# Garcia Turismo

Sistema financeiro e de frota da Garcia Turismo.

## Abrir o projeto

Use Live Server no VS Code ou rode:

```bash
python -m http.server 8000
```

Acesse:

```text
http://localhost:8000
```

## Arquivo de entrada

O arquivo principal é `index.html`, mas ele só carrega CSS e `src/app.js`.
